Super Admin Setup Guide

For maximum enterprise security, Super Administrator accounts are initialized via an authorized one-time CLI bootstrap command on your hosting server or local console.

# Run in your project directory:
node scripts/bootstrap-superadmin.js

# Or specify a custom administrator email:
node scripts/bootstrap-superadmin.js owner@yourdomain.com
  1. The bootstrap tool generates a cryptographically secure one-time password.
  2. It provisions your Firebase Auth record and registers role as superadmin.
  3. Upon your first login, the system mandates that you set your permanent personal password.
  4. No administrator passwords are ever stored in source code or Firestore documents.
