Super Admin Bootstrap Guide

To ensure absolute security, the Super Admin account is provisioned via an authorized one-time bootstrap script.

# Run in your project terminal:
node scripts/bootstrap-superadmin.js

# Or specify a custom administrator email:
node scripts/bootstrap-superadmin.js owner@yourdomain.com
  1. The script generates a 16-character cryptographically secure temporary password.
  2. It creates your Firebase Auth user and marks role as superadmin.
  3. On first login, you will be mandated to set your permanent password.
  4. No password is ever stored in source code or Firestore.
